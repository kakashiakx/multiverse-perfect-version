# Security Policy

## Supported Versions

The project is currently in its initial stage. Please use the latest version of the repository and keep your local checkout updated.

| Version | Supported |
| ------- | --------- |
| main    | ✅ Yes    |

## Reporting a Vulnerability

If you discover a security vulnerability, please do not open a public issue. Instead, report it privately to the repository maintainers via GitHub Security Advisories or by contacting the project owner directly.

Please include:
- A clear description of the issue
- Steps to reproduce it
- Impact assessment
- Any proposed mitigation or patch

We will review the report as quickly as possible and keep you informed about the progress.

## Disclosure Policy

We ask that security issues be handled responsibly and not disclosed publicly until a fix is available or a reasonable remediation plan is in place.

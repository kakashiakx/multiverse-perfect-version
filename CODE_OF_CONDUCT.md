# Code of Conduct

## Our Pledge

We are committed to making participation in this project a welcoming and respectful experience for everyone. We value empathy, kindness, constructive feedback, and respect for differing viewpoints.

## Our Standards

Examples of behavior that contributes to a positive environment include:

- Being respectful and considerate
- Giving and accepting constructive feedback gracefully
- Taking responsibility for mistakes and learning from them
- Focusing on what is best for the project community

Unacceptable behavior includes harassment, personal attacks, publishing private information without permission, and conduct that would be inappropriate in a professional setting.

## Scope and Enforcement

This code applies in project spaces and when representing the project publicly. Project maintainers are responsible for clarifying and enforcing these standards. Report concerns privately to the repository owner through GitHub.
